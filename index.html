Cómo se usa: 1) elige todas las fotos del trabajador. 2) Gira cada una con ↶ ↷ hasta que se lea bien. 3) Arrastra con el ratón sobre la foto para recortar el carnet (opcional). 4) Ordénalas con ▲▼ (DNI delante, DNI detrás, tarjeta…). 5) "Guardar".
Las fotos se colocan de dos en dos por fila. Usa Grande para que ocupe todo el ancho o Fila nueva para empezar línea.
